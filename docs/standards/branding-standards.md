# KiloNorth Branding Standards (v1.3)

## ⚡ Core Identity: "Hyper-Surge"
The KiloNorth brand is defined by a high-depth, energetic visual language that combines Canadian heritage with cutting-edge electric mobility.
- **Logo Mark**: A geometric "KN" monogram integrated with a dynamic electric surge and a subtle maple leaf.
- **Vibe**: "Elite Neat" — Minimalist but high-impact.

### 🎨 Color Palette
Standardized on highly legible emerald and noir tones:
- **Primary Emerald**: `#10b981` (Used for author highlights, progress indicators, and active states).
- **Success Accent**: `#34d399`.
- **Warning**: `#fbbf24`.
- **Danger**: `#ef4444`.

### 🔠 Typography
- **Font**: Inter / High-end Sans-Serif.
- **Weights**: 
  - **Regular Highlights**: `800`.
  - **Elite Highlights**: `950` (Used for name signatures and primary numbers).
- **Styling**: `uppercase` with `0.1em` to `0.25em` letter-spacing for metadata and technical labels.

### 📐 Layout Principles
- **Surgical Padding**: Use consistent `0.5rem` / `0.75rem` spacing within cards.
- **Glassmorphism**: 
  - `rgba(var(--bg-card-rgb), 0.4)` background.
  - `16px` backdrop-filter blur.
  - `1px` subtle borders.
- **Horizontal Integrity**: Enforce `white-space: nowrap` for signatures and primary metrics on mobile to prevent awkward wrapping.
